# Panda Control Vent 0.1.3

- `Panda-Control-Vent-0.1.3-OTA.bin`: versioned firmware.
- `Panda-Control-Vent-OTA.bin`: byte-identical permanent download name.
- `SHA256SUMS`: checksums for these two filenames.

Follow the [installation/update guide](../docs/INSTALLATION.md).
Expected displayed firmware after restart: **0.1.3**.

This release adds active-material detection for the single-slot AMS HT while
preserving ordinary AMS and external-spool handling. The
[changelog](../CHANGELOG.md#013---2026-10-25) describes the changes and
validation.
