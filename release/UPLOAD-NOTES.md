# Panda Control Vent 0.1.7

- `Panda-Control-Vent-0.1.7-OTA.bin`: versioned firmware.
- `Panda-Control-Vent-OTA.bin`: byte-identical permanent download name.
- `SHA256SUMS`: checksums for these two filenames.

Follow the [installation/update guide](../docs/INSTALLATION.md).
Expected displayed firmware after restart: **0.1.7**.

This release improves recovery after a Wi-Fi connection drops and restores the
existing DHCP watchdog during reconnection. Existing settings are preserved.
See the [changelog](../CHANGELOG.md#017---2026-10-31).
